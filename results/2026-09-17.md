All numbers below are **local measurements** on 2 × B65, Qwen3.8-27B-FP8, TP=2, MTP-2, max-model-len 180,224, batch budget 256, max sequences 2, XPU Graph off, GPU utilization 0.95, no CPU weight offload, 16 GiB container RAM and zero container swap.

Short benchmark: three single streams and one pair per candidate, plus warm-up. The production control brackets candidate runs and its average is an interpolation. Prompts had matched structure but different random markers; they were not byte-identical. `decode tok/s = completion_tokens / (last_stream_event − first_content_event)`; concurrent aggregate `tok/s = sum(completion_tokens) / pair_wall_time`. TTFT is elapsed request start to first content/reasoning delta. These metrics are not interchangeable. Some setups classify reasoning deltas differently; reproduce the definition before comparing.

All candidate long requests returned HTTP 200, generated 256 tokens, and included the expected marker. The ~125K pair's two TTFTs were about 212 and 399 seconds. The soak sequences were seeded but stopped at slightly different completed-cycle counts. Neither candidate had EngineCore crash, DEVICE_LOST, Xe reset/fault, OOM, or container swap during these tests. A historical production 2 × ~125K measurement was 407.76 s, but used a different context limit and is not treated as a matched control.
